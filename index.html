③ GitHubへ反映

同じパスのファイルは上書き、新しいパスのファイルは追加します。1回の更新を1つのコミットにまとめます。

ファイルを選択すると更新ボタンが有効になります。
GitHubアクセストークンの作り方
  1. Safariで github.com/settings/personal-access-tokens/new を開く。
  2. Token nameを入力し、Expirationを設定。
  3. Repository accessは「Only select repositories」を選び、更新したいリポジトリだけを指定。
  4. Repository permissionsの「Contents」を「Read and write」にする。
  5. Generate tokenを押し、表示されたトークンを上の欄に貼り付ける。

トークンはこのページを閉じると保持されません。GitHubの設定画面や他人にトークンを送らないでください。

GitHub REST APIを使用します。ファイル内容は選択後、GitHubへ直接送信されます。
